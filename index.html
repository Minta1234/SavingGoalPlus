Method 1 • Recommended for Browser Testing

1. Appetize.io (Cloud iOS Simulator in Chrome/Edge)

Appetize.io runs real iOS virtual devices directly in your web browser. You do not need a Mac or iPhone. You get free simulator streaming minutes every month!

  1. 1
    Download the iOS Build Artifact from GitHub

    Go to our GitHub Actions workflow: download SavingGoalPlus-iOS.xcarchive.zip from GitHub Releases.

  2. 2
    Upload to Appetize.io

    Visit appetize.io/upload and drag-and-drop the simulator .app or zipped build.

  3. 3
    Interact in Your Browser

    Select iPhone 15 or 16, choose iOS 17+, and click Play. You can click, scroll, and test notifications inside your normal Windows desktop browser!

Method 2 • Real Device Cloud

2. BrowserStack App Live & Sauce Labs

If you need to test on physical real iPhones (e.g. iPhone 15 Pro, iPhone 16) without purchasing hardware, use cloud device labs:

  • ✦
    BrowserStack App Live: Upload our SavingGoalPlus-v1.0.0-unsigned.ipa directly to BrowserStack. It streams video and touch controls from a real iPhone in a data center.
  • ✦
    LambdaTest / Sauce Labs: Equivalent services offering free trial minutes to run and debug iOS IPA packages interactively.
Method 3 • Automated Cloud CI

3. Free Cloud macOS via GitHub Actions

You do not need to buy a \$1,000 Mac to build, verify, and unit-test iOS apps. Our automated CI workflow handles everything on Apple hardware in the cloud: 

# Trigger iOS Cloud Compilation on macOS runner:
git tag v1.0.1
git push origin v1.0.1

GitHub Actions boots a real macos-latest runner with Xcode, compiles the entire SwiftUI code, executes all unit tests, verifies mathematical rate parity, and packages the .xcarchive.zip for download automatically.

Method 4 • Physical Sideloading

4. Install without App Store (AltStore / Sideloadly)

If a friend or colleague has an iPhone or iPad, you can install the build directly from Windows without paying $99/year for an Apple Developer Account:

  1. 1
    Download Sideloadly on Windows: Install sideloadly.io (free for Windows 10/11).
  2. 2
    Plug in iPhone via USB: Drag SavingGoalPlus-v1.0.0-unsigned.ipa into Sideloadly and enter a free personal Apple ID to sign and install it directly!
